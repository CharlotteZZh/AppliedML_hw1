# Titanic survival prediction

The assignment has two deliverables:

- `AppliedML_hw1.ipynb`: all assignment code in 29 separate code cells, with explanations, executed results, 12 displayed tables, and five embedded figures.
- `output/pdf/AppliedML_hw1_Report.pdf`: the separate 11-page written report.

Open the notebook in a Jupyter-compatible editor or Google Colab. Its saved
outputs are already included. To reproduce them, select Restart Kernel and Run
All. Keep the original `titanic/train.csv` and `titanic/test.csv` data available;
Colab will prompt for uploads if needed. No helper scripts, image exports, or
CSV exports are required or generated.

Local dependencies are listed in `requirements.txt`. The analysis was run with
Python 3.10.7 and scikit-learn 1.4.1.post1.

Before submission, add your actual shareable Colab notebook link to page 1 of
the report. Review the notebook and the AI disclosure and update the disclosure
with any work you personally complete.
